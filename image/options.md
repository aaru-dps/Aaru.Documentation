## Command description

This operation will list all options supported by the writable media image plugins recognized by Aaru.

## Command usage

```text
USAGE:
    aaru image options [OPTIONS]

OPTIONS:
    -h, --help    Prints help information
```

## Example

```bash
aaru image options example.iso
```
